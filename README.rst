char-sheet
*********************
Overview
********

View/Edit a DND 5e (2014) JSON Character Sheet.

Build and Run
***************

- To build the application run ``cargo build``::

  $ cargo build

- To execute the application run ``cargo run`` or ``./target/debug/char-sheet``::

  $ cargo run -- --json-file <path to json char sheet>
  $ ./target/debug/char-sheet -- --json-file <path to json char sheet>

Test
****

- To execute the tests run ``cargo test``.

Updating this file
******************

- Within the python venv use ``restview README.rst`` to view this file in a browser.
