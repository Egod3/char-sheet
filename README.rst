char-sheet
*********************
Overview
********

View/Edit a DND 5e (2014) JSON Character Sheet.

Build and Run
***************

- To build the application run ``cargo build``::

  $ cargo build

- To execute the application run ``cargo run`` or ``./target/debug/char-sheet``::

  $ cargo run
  $ ./target/debug/char-sheet
